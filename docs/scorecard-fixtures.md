# Scorecard scan fixtures

Ground truth read by hand from four real cards (photos not committed — they are
gitignored). Use these to check the deployed scanner: scan the same card in the
app and compare. Any disagreement is a scanner bug worth fixing, not a card to
correct by hand.

Each row validated three ways: the 18 values are a permutation of 1–18, par
totals 72 (36/36), and the odd indexes all fall on one nine — the convention
essentially every course follows.
